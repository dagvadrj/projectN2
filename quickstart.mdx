This guide takes you from a fresh clone to the app running at `http://localhost:3000`.

## Prerequisites

Before you begin, you must have:

- Node.js 22.14 (the version in `.nvmrc`). The app requires Node `>=22.14 <23`.
- A Supabase project. You need its URL and API keys from **Project Settings > API**.

## Get started

<Steps>
  <Step title="Install Node and dependencies">
    Switch to the Node version in `.nvmrc`, then install dependencies.

    ```bash
    nvm use
    npm install
    ```
  </Step>
  <Step title="Configure environment variables">
    Copy the example environment file.

    ```bash
    cp .env.example .env.local
    ```

    Set the Supabase values from **Project Settings > API** in your Supabase dashboard.

    ```bash .env.local
    NEXT_PUBLIC_SUPABASE_URL=https://<project-ref>.supabase.co
    NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=<publishable-key>

    # Server-only key for API routes and admin operations
    SUPABASE_SECRET_KEY=<secret-key>
    ```

    Older Supabase projects without a publishable key can set `NEXT_PUBLIC_SUPABASE_ANON_KEY` instead.

    <Warning>
      Keep `SUPABASE_SECRET_KEY` server-only. Never prefix it with `NEXT_PUBLIC_` and never commit it to the repository.
    </Warning>

    Payments (QPay, SocialPay, bank transfer), Cloudinary images, Cloudflare R2 model storage, and AI kitchen renders are optional. Each optional feature needs all of its variables set, or none. Production deployments also need `APP_URL` for trusted payment callbacks.

    Check your configuration:

    ```bash
    npm run env:check
    ```
  </Step>
  <Step title="Apply database migrations">
    Apply the versioned SQL migrations in `supabase/migrations/` to your Supabase project, in filename order. The migrations create the catalog, inventory, orders, payments, merchant stores, roles, and kitchen planner tables.

    With the Supabase CLI linked to your project:

    ```bash
    supabase db push
    ```
  </Step>
  <Step title="Start the dev server">
    ```bash
    npm run dev
    ```

    Open [http://localhost:3000](http://localhost:3000).
  </Step>
</Steps>

## Validate changes

Run these commands before you open a pull request:

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

`npm run verify` runs the environment check, style check, lint, typecheck, tests, and build in one command.
