taivlgamn is a furniture e-commerce app built around an immersive 3D room planner. Shoppers browse furniture, customize materials and colors live in 3D, and drag pieces into a virtual room that matches their real dimensions. Merchants manage their own stores and products. Admins manage the whole marketplace.

The app runs on Next.js 15 (App Router) with TypeScript. Supabase provides authentication, the database, and storage. Three.js with React Three Fiber renders the 3D views.

## Main routes

| Route | Description |
| --- | --- |
| `/` | Home page with hero, collections, banners, reviews, and an inspiration gallery |
| `/catalog` | All furniture with filters, sorting, and search |
| `/catalog/[category]` | Listings for one category, such as sofas, beds, or wardrobes |
| `/catalog/stores/[id]` | Public profile and products for one merchant store |
| `/product/[id]` | Product detail with the 3D customizer |
| `/planner` | Virtual room planner |
| `/kitchen` | Modular kitchen planner |
| `/kitchens` | Published kitchen designs |
| `/cart`, `/wishlist` | Shopping cart and saved products |
| `/checkout` | Server-priced order confirmation and delivery details |
| `/orders/[id]` | Order detail with QPay, SocialPay, or bank transfer instructions |
| `/account` | Saved designs, order history, and wishlist |
| `/login`, `/register` | Sign in and create an account |
| `/merchant` | Merchant dashboard for store profile, products, and fulfillment |
| `/admin` | Admin dashboard for furniture, 3D models, orders, users, and analytics |

## Roles

Supabase authenticates every user. The `role` column in the `profiles` table controls access:

- **Customers** shop, save room designs, and track orders from `/account`.
- **Merchants** sign in to `/merchant`. Only an admin can assign the merchant role.
- **Admins** sign in to `/admin`. Signing up with Google or Apple never grants admin access.
